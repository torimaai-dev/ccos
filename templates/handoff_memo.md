# Handoff Memo Template

このテンプレートは、AIとの会話や作業ログを、次の対話・作業・レビューへ引き継ぐためのメモです。

## Context

背景を書きます。

- 何について話していたか
- どの作業の続きか
- 何を解決したかったか

## Goal

次に達成したいことを書きます。

```text
例: READMEの説明を短くしつつ、CCOSの思想が伝わるようにする。
```

## Current status

現在の状態を書きます。

- 完了したこと
- 途中のこと
- まだ確認が必要なこと

## Decisions

すでに決めたことを書きます。

- 採用済みの方針
- 維持したい表現
- 変更しない前提

## Open questions

まだ決まっていないことを書きます。

- 確認が必要なこと
- 判断待ちのこと
- 次に相談すること

## Constraints

守るべき条件を書きます。

- 作業範囲
- 表現のトーン
- 触らないファイル
- 公開してよい情報の範囲

## Suggested next action

次にやるとよいことを書きます。

```text
例: docs/CONCEPT.mdから、READMEに戻すべき1段落だけを抽出する。
```

## Notes

次の作業者やAIに渡したい注意を書きます。
